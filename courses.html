CSE Coursework & Learning Outcomes

Detailed breakdown of core academic coursework completed during my Computer Science & Engineering degree at North South University, including topics covered and practical learning outcomes.

01 Completed CSE Courses

CSE 221 • Algorithms & Data Structures

Data Structures & Algorithms

Topics Covered: Trees, Graphs, Dynamic Programming, Greedy Algorithms, Sorting, Hashing, Time & Space Complexity Analysis.

Key Learning Outcomes: Mastered efficient problem-solving paradigms, optimizing computational time and memory footprints for complex backend systems.

CSE 311 • Database Systems

Database Management Systems

Topics Covered: Relational Algebra, SQL, Normalization (1NF to BCNF), Indexing, Transactions, Concurrency Control, NoSQL basics.

Key Learning Outcomes: Designed robust relational schemas, wrote optimized complex queries, and ensured ACID compliance for high-load database transactions.

CSE 327 • Software Engineering

Software Engineering & System Design

Topics Covered: Agile/Scrum Methodologies, UML Modeling, Design Patterns, Testing Frameworks, CI/CD pipelines.

Key Learning Outcomes: Gained hands-on team engineering experience, building modular, maintainable software architectures aligned with industry standards.

CSE 331 • Computer Networks

Computer Networks

Topics Covered: OSI & TCP/IP Models, Routing Protocols, Socket Programming, HTTP/HTTPS, DNS, Network Security.

Key Learning Outcomes: Understood packet transmission mechanics, network socket communication, and protocols underpinning modern web infrastructure.

CSE 373 • Artificial Intelligence

Artificial Intelligence

Topics Covered: Heuristic Search, A* Algorithm, Knowledge Representation, Propositional Logic, Intro to Machine Learning & Neural Networks.

Key Learning Outcomes: Built autonomous agents and intelligent search systems, laying the groundwork for modern LLM and RAG specialization.
