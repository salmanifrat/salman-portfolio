TaxEaseBD

RAG-Powered Legal & Tax Compliance Assistant for Bangladesh

An asynchronous Retrieval-Augmented Generation (RAG) assistant designed to index complex National Board of Revenue (NBR) legal statutes, annual Finance Act revisions, and official Statutory Regulatory Orders (SROs). Built to eliminate the high legal barrier to entry and ambiguous taxation questions faced by everyday Bangladeshi citizens, freelancers, and small business owners.

The system features an automated legal document ingestion pipeline with semantic sliding-window chunking that preserves strict statutory clause boundaries. Vector embeddings are stored in a dense FAISS index and retrieved in real-time. Generation is orchestrated through Groq Cloud LPU acceleration with LLaMA 3, enforcing anti-hallucination prompt constraints that require direct clause citations for every answer.

● Completed Database Systems Full-Stack Architecture ACID Compliant

Departmental Store Management System

Relational Database Engine & Retail Inventory Management Platform

An end-to-end supermarket retail and inventory management platform designed to automate high-volume retail operations. Centralizes stock auditing, supplier procurement cycles, checkout billing point-of-sale (POS) interactions, and comprehensive transactional audit logging into a single cohesive architecture.

Engineered a robust, normalized MySQL relational schema guaranteeing referential integrity, primary and foreign key constraints, and full ACID transaction reliability. Built a hybrid backend utilizing PHP for request routing and cashier session management, alongside Python data processing routines for automated sales analytics, low-inventory notifications, and supplier re-order forecasting.

Engineering Highlights
  • Designed normalized relational database schema (3NF/BCNF) with optimized indexing for fast multi-table joins
  • Implemented database triggers and stored procedures for real-time inventory deductions upon POS checkout
  • Built backend query orchestration with PHP and Python scripts for transactional sales metrics and revenue summaries
  • Engineered role-based access control (RBAC) separating cashier checkout functions from managerial administrative panels
  • Enforced ACID transaction boundaries to prevent race conditions during concurrent stock updates and billing

● Completed Systems Programming Pure C File Streams

Mobile Phone Management System

Low-Level Procedural Terminal Engine with File Stream Persistence

A standalone procedural inventory and device management engine engineered entirely in pure C without third-party frameworks or external libraries. Designed to model real-world mobile retail dealership operations, handling device inventories, unique IMEI registration, customer warranty tracking, and sales auditing through a responsive command-line interface.

Implemented low-level file I/O streams for permanent disk-based record persistence, enabling reliable binary and structured text data storage across application sessions. Built dynamic memory management routines and raw pointer manipulation to maintain in-memory record catalogs, coupled with optimized search and sorting algorithms for instantaneous record retrieval.

Engineering Highlights
  • Architected modular C data structures (`struct`) modeling multi-field device specifications, IMEI identifiers, and warranty records
  • Implemented low-level file stream handlers (`fopen`, `fread`, `fwrite`, `fseek`) ensuring reliable disk persistence
  • Engineered linear and binary search algorithms for sub-millisecond querying of device records by model, serial, or price range
  • Integrated defensive user-input validation and buffer management preventing memory leaks, pointer corruption, and overflows
  • Structured modular header files and source units to maintain strict procedural separation of concerns

● Ongoing Computer Vision Space AI Out-of-Distribution

Mars Image Novelty Detection

Open-Set Novelty & Anomaly Detection for Martian Surface Imagery

An active computer vision and machine learning research project addressing the operational constraints of planetary rovers and orbiters. Investigating open-set methodologies to classify Martian surface imagery into three epistemic domains: familiar terrain, unfamiliar anomalies, and uncertain observations.

Due to delayed orbital communication windows and severe transmission bandwidth limitations, rovers cannot stream every captured frame back to Earth. This system aims to provide on-rover autonomous intelligence capable of recognizing scientifically novel geological formations, prioritizing anomalous observations for downlink without waiting for manual human-in-the-loop review.

Research Milestones Completed Stage 2 of 5 (~25% · Literature Review & Dataset Curation)
Research & Engineering Highlights

  • Benchmarking detection fidelity against traditional out-of-distribution (OOD) and reconstruction-based baselines
